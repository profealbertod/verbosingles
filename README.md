# Irregular Verbs Challenge · IES Andrés Benítez

Aplicación educativa para practicar verbos irregulares en inglés.

> Aplicación desarrollada en el marco del Proyecto STEAM 4.0 / Programa de Cooperación Territorial Código Escuela 4.0

## Desarrollo local
Requiere Node.js 20+ y npm.

```bash
npm install
npm run dev
npm run build
```

## GitHub Pages
El proyecto configura Vite para la ruta `/verbosingles/`. En GitHub, abre Settings → Pages y selecciona GitHub Actions. El flujo incluido construye la app y la publica al hacer push a main.

## Primera versión
Incluye ejercicios de pasado simple, participio y traducción, diccionario con búsqueda, audio con síntesis de voz del navegador y progreso local. El diccionario es inicial y debe ampliarse/revisarse en siguientes iteraciones.
